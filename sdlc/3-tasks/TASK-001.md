## Цель

Создать базовое Laravel 12 приложение на PHP 8.2+ с границами модулей Auth,
Queue, Service, MCP, Platform и Observability.

## Объём

- Laravel application skeleton;
- конфигурация MariaDB/MySQL и Redis через environment;
- базовая структура прикладных actions/services без бизнес-логики в
  контроллерах;
- единый формат REST-ошибок и correlation id;
- команды запуска тестов и статического анализа;
- `.env.example` без секретов.

## Требования реализации

1. REST и MCP должны вызывать общий прикладной слой.
2. Конфигурация не содержит environment-specific значений в коде.
3. Логи структурированы и включают correlation id.
4. Технический health route не требует JWT.
5. Выбранные библиотеки совместимы с PHP 8.2+ и Laravel 12.

## Критерии приёмки

1. Приложение загружается и отвечает на health route.
2. Конфигурация соединений считывается из окружения.
3. Unit test запускается документированной командой.
4. В репозитории нет credentials и JWT secrets.
5. Архитектурные каталоги и зависимости модулей описаны в README.

## Проверки

- smoke test bootstrap;
- тест генерации correlation id;
- проверка конфигурации без реальных секретов.

## Definition of Done

Код, конфигурация и инструкция готовы для параллельной реализации последующих
задач; базовые проверки проходят в чистом окружении.
