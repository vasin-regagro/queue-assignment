## Definition of Ready

Задача готова к реализации, если:

- все зависимости завершены;
- ссылки на PT/spec существуют;
- критерии приёмки не противоречат PRD 0.5;
- спорное решение возвращено на предыдущий этап, а не придумано в коде.

## Общий Definition of Done

- реализованный код и миграции;
- автоматические позитивные и негативные тесты;
- проверка авторизации и идемпотентности, где применимо;
- обновлённая документация интерфейса/эксплуатации;
- доказательство трассируется к TASK, UC и PT;
- обязательные CI checks проходят.
