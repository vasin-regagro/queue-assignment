# UC-008-ACTOR-002-EVT-008-ENT-004-SERVICE-STARTED-IN-SERVICE

## Цель

Начать обслуживание вызванной записи, соблюдая лимит одной обслуживаемой
записи на оператора.

## Интерфейсы

REST изменяющая операция или MCP `start_service`; обязателен idempotency key.

## Предусловия

Оператор назначен; QueueEntry имеет `CALLED`; оператор не связан с другой
записью `SERVING`.

## Основной поток

1. Авторизовать оператора и проверить назначение.
2. Разрешить идемпотентный запрос.
3. Атомарно заблокировать запись и ограничение занятости оператора.
4. Повторно проверить `CALLED` и отсутствие другой `SERVING`.
5. Выполнить `CALLED → SERVING`.
6. Записать оператора и `service_started_at`.
7. Сохранить EVT-008 и результат; для MCP — аудит.

## Альтернативы и ошибки

Неверное состояние, запись отменена, оператор занят, отсутствует назначение,
конфликт idempotency key.

## Результат

QueueEntry обслуживается текущим оператором. Другой оператор этой Queue может
параллельно обслуживать другую запись.

## Критерии приёмки

1. У одного оператора не более одной `SERVING`.
2. У Queue может быть несколько `SERVING` разных операторов.
3. `CALLED → SERVING` выполняется один раз.
4. Частичное назначение оператора невозможно.
