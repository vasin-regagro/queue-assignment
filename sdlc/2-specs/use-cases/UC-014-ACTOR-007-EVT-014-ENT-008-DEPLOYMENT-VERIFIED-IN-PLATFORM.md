# UC-014-ACTOR-007-EVT-014-ENT-008-DEPLOYMENT-VERIFIED-IN-PLATFORM

## Цель

Развернуть и доказуемо проверить чистый контейнерный контур MVP.

## Предусловия

Доступны Docker/Compose, конфигурация и значения обязательных переменных
окружения.

## Основной поток

1. Проверить отсутствие секретов в исходниках и образах.
2. Выполнить `docker compose up -d`.
3. Дождаться health `app`, `nginx`, `db`, `redis`.
4. Выполнить миграции.
5. Запустить автоматические тесты.
6. Проверить REST по HTTPS.
7. Проверить MCP Streamable HTTP по HTTPS.
8. Подтвердить TLS termination на Nginx.
9. Зафиксировать версии и EVT-014.

## Альтернативы

Неготовый компонент, ошибка миграции, недоступный endpoint или утечка секрета
дают `NOT_READY` с точной причиной; частичный контур не считается успешным.

## Результат

Воспроизводимое окружение готово для evaluation либо имеет диагностированный
блокер.

## Критерии приёмки

1. Одна команда запускает четыре обязательных сервиса.
2. Health-check показывает конкретную зависимость.
3. Инструкции воспроизводимы в чистом окружении.
4. Целевая нагрузка проверяема.
