# UC-007-ACTOR-002-EVT-007-ENT-004-NEXT-USER-CALLED-IN-SERVICE

## Цель

Атомарно вызвать первую ожидающую запись назначенной очереди.

## Интерфейсы

REST изменяющая операция или MCP `call_next_user`; обязателен idempotency key.

## Предусловия

Оператор авторизован и назначен на Queue. В Queue существует `WAITING`.

## Основной поток

1. Проверить JWT, роль и активное назначение.
2. Разрешить идемпотентный запрос.
3. В транзакции выбрать первую `WAITING` по `joined_at, id` с блокировкой.
4. Выполнить `WAITING → CALLED`, установить `called_at`.
5. Сохранить результат и EVT-007.
6. Вернуть разрешённые оператору поля.
7. Для MCP создать аудит.

## Альтернативы и ошибки

- очередь пуста — бизнес-результат `NO_WAITING_ENTRIES`;
- оператор не назначен — forbidden;
- Queue закрыта — активную запись всё равно разрешено вызвать;
- конкурент уже выбрал запись — поиск продолжается либо возвращается пустой
  результат;
- конфликт ключа — без изменения.

## Результат

Ровно одна ранее ожидающая QueueEntry имеет `CALLED`.

## Критерии приёмки

1. FIFO соблюдён.
2. Два конкурентных оператора не получают одну запись.
3. Отменённая запись не выбирается.
4. Ответ содержит только талон, статус, joined time и display name.
