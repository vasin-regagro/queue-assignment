# UC-003-ACTOR-003-EVT-003-ENT-003-ASSIGNMENT-CHANGED-IN-QUEUE

## Цель

Назначить оператора на одну или несколько очередей либо снять назначение.

- [ENT-003](../entities/ENT-003-OPERATOR-ASSIGNMENT-IN-QUEUE.md)

## Предусловия

Администратор и оператор существуют; оператор имеет требуемую роль; Queue
существует; вызов REST содержит ключ идемпотентности.

## Основной поток

1. Проверить администратора.
2. Проверить User оператора и Queue.
3. При назначении создать уникальную активную связь.
4. При снятии установить `revoked_at`.
5. Сохранить идемпотентный результат.
6. Зафиксировать EVT-003.

## Альтернативы и ошибки

- оператор/Queue не найдены;
- User не имеет роли оператора;
- активная связь уже существует или уже снята — повтор без нового эффекта;
- попытка через MCP — недоступно;
- конфликт ключа — без изменения.

## Результат

Оператор получает или теряет право на будущие операторские операции в Queue.
Исторические QueueEntry не изменяются.

## Критерии приёмки

1. Один оператор назначается в несколько очередей.
2. Несколько операторов назначаются в одну очередь.
3. Дубликат активной пары невозможен.
4. Снятое назначение немедленно запрещает новую операцию.
