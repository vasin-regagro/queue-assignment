# UC-002-ACTOR-003-EVT-002-ENT-002-QUEUE-STATE-CHANGED-IN-QUEUE

## Цель

Создать очередь либо изменить её доступность для новых записей.

## Предусловия

Администратор авторизован; запрос пришёл через REST; для изменения Queue
существует; передан `Idempotency-Key`.

## Основной поток

1. Проверить JWT и роль администратора.
2. Разрешить идемпотентный запрос.
3. Для создания проверить имя и создать Queue в `CLOSED`.
4. Для открытия проверить `CLOSED` и выполнить `CLOSED → OPEN`.
5. Для закрытия проверить `OPEN` и выполнить `OPEN → CLOSED`.
6. Не менять активные QueueEntry и счётчик талонов.
7. Сохранить результат и EVT-002.

## Альтернативы и ошибки

- нет роли — forbidden;
- Queue отсутствует — not found;
- состояние уже целевое — согласованный повтор без нового эффекта;
- тот же ключ с другими параметрами — idempotency conflict;
- административный MCP-вызов — tool отсутствует.

## Результат

Queue имеет целевое состояние. При `CLOSED` новые записи запрещены, но
обслуживание активных продолжается.

## Критерии приёмки

1. Только REST-администратор меняет Queue.
2. Новая Queue закрыта.
3. Закрытие не изменяет QueueEntry.
4. Нумерация после повторного открытия продолжается.
