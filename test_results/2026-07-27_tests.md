## Покрытые бизнес-риски

1. Неавторизованный пользователь не получает доступ к защищённым REST/MCP
   операциям.
2. Административные операции недоступны обычному пользователю.
3. Изменяющие операции требуют корректный ключ идемпотентности.
4. Повтор ключа с другими параметрами отклоняется.
5. В закрытую очередь нельзя записаться.
6. В одной очереди нельзя иметь две активные записи.
7. Чужую или завершённую запись нельзя отменить.
8. Оператор должен быть назначен на очередь.
9. Оператор не может одновременно обслуживать две записи.
10. Завершить обслуживание может только обслуживающий оператор.
11. MCP ошибки журналируются, а секретные поля исключаются из payload.
12. Истёкшие и отозванные MCP-токены не принимаются.
13. Legacy SSE принимает сообщения только существующей сессии того же
    пользователя.
14. Retention удаляет только истёкшие терминальные данные.
15. Повторный запуск default seeder не создаёт дубликаты и не сбрасывает
    рабочее состояние очереди.
16. Публичное табло доступно без JWT и показывает все очереди.
17. Активные записи отображаются по FIFO, а `COMPLETED`/`CANCELLED`
    исключаются.
18. Email, внутренние user ID и изменяющие controls отсутствуют в публичном
    HTML.
19. Пустые состояния и автоматическое обновление через 15 секунд работают.
